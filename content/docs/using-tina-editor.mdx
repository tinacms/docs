## Accessing the CMS 

On running, TinaCMS creates a **static build** of your site. This (and the editor) can be accessed at the `/admin/index.html` route of your website.

<Callout variant="info"
  body={<>
    In the video above, [NextJS rewrites](https://nextjs.org/docs/app/api-reference/config/next-config-js/rewrites) are used to access `/admin/index.html` on `/admin`.
  </>}
/>

If there's no current session, you'll be prompted to login.

<imageEmbed image={{ src: "/img/docs/using-tina-editor/tina-login.png", alt: "TinaCMS Login Page" }} caption="The TinaCMS login screen at /admin" />

## Making Changes

Making changes is super simple.

One or more Collections (**content structures**) will appear in the Global Navigation. Each takes you to the Document List for that Collection.

<imageEmbed image={{ src: "/img/docs/using-tina-editor/tina-list-page.png", alt: "TinaCMS Editor List Page" }} caption="The Global Navigation and the Document List for a collection" />

Clicking on a document takes you to its editor.

The **save** button adds any changes into your content files.

<imageEmbed image={{ src: "/img/docs/using-tina-editor/tina-editor.png", alt: "TinaCMS Editor Document Page" }} caption="The document editor, with the live site preview on the right" />
