A structured input that stores date values as ISO 8601 timestamps. Editors pick the date from a calendar, and can pick a time as well when you set `ui.timeFormat`.

TinaCMS converts the picked date from the editor's local time and saves it in UTC.

## Examples

### Simple field

```javascript
{
  type: 'datetime',
  name: 'date',
  label: 'Date'
}
```

![Date field with its calendar open](/img/docs/reference/date-field.png)

### Field with custom date format

Set `ui.dateFormat` to change how TinaCMS shows the date to editors. TinaCMS still saves the full timestamp, such as `2026-10-09T00:00:00.000Z`.

```javascript
{
  label: "Date",
  name: "date",
  type: "datetime",
  ui: {
    dateFormat: "YYYY-MM-DD",
  },
}
```

![Date field showing 2026-10-09](/img/docs/reference/date-field-custom-format.png)

### Field that saves only the date

A `datetime` field always saves a full timestamp. TinaCMS turns the value back into a date before it writes the file, even when `ui.parse` returns a bare date.

To save a bare `YYYY-MM-DD`, use a `string` field with the `date` component:

```javascript
{
  label: "Date",
  name: "date",
  type: "string",
  ui: {
    component: "date",
    format: (value) =>
      /^\d{4}-\d{2}-\d{2}$/.test(value)
        ? `${value}T00:00:00`
        : value,
    parse: (value) => {
      if (!value) return value;
      const date = new Date(value);
      return [
        date.getFullYear(),
        String(date.getMonth() + 1).padStart(2, "0"),
        String(date.getDate()).padStart(2, "0"),
      ].join("-");
    },
  },
}
```

`parse` receives the picked date as an ISO string and saves the day the editor picked, in their local time. `format` reads a stored `2026-10-09` as local midnight. Without it, the picker reads that value as midnight UTC, and editors west of UTC see October 8.

GraphQL treats this field as a string, so your queries can't use the `after` and `before` filters that `datetime` fields support.

If you switch an existing `datetime` field to this, quote each value in your files first, for example `date: '2026-10-09'`. YAML reads an unquoted date as a date rather than a string, and indexing then fails with `Unable to seed` for that file.

### Field including time picker

You can add a timepicker to the date UI by supplying the `ui.timeFormat` property.

```javascript
{
  label: "Date",
  name: "date",
  type: "datetime",
  ui: {
    timeFormat: "HH:mm"
  },
}
```
