---
title: 什么是 TinaCMS？
last_edited: '2026-09-11T00:00:00.000Z'
---

[TinaCMS](https://tina.io) 是一个面向开发者的、基于 Git 的无头 CMS。

<Callout
  body={<>
    无头 CMS 是一种通过 API 存储内容并将其发送到任何网站或应用的工具，它不控制前端的实现方式。
  </>}
  variant="info"
/>

它允许你使用 React 构建自定义的内容编辑门户，所有更改都以纯文件形式存储并直接提交到 Git。

它与你的网站相互独立：网站接入 TinaCMS，并从 Git 中拉取内容。
